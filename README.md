# 한국노동사회연구소 40주년 기념 웹사이트

이 저장소는 한국노동사회연구소 40주년 기념일(2026년 4월 23일)까지 D‑데이를 표시하고, 매일 카드뉴스를 게시하는 간단한 정적 웹사이트 예시입니다. HTML, CSS, JavaScript만으로 구성되어 있어 GitHub Pages나 Netlify 등 정적 웹 호스팅 서비스에 손쉽게 업로드할 수 있습니다.

## 구성

```
klsi-40th-anniversary/

├── card2.png        # 예시 이미지 2
├── card3.png        # 예시 이미지 3

```

## 주간회의 업무관리 시스템 (meeting.html)

사람 · 사업 · 일정을 연결하는 관계형 업무관리 도구입니다. 의존성 없이 바닐라
JavaScript + 브라우저 `localStorage`로 동작하며, cafe24 등 어떤 호스팅에도
파일 업로드만으로 배포됩니다.

**데이터 스토어 7종** (1:1 관계인 재정·회원변동은 주간회의 레코드에 병합):
`people`(사람) · `projects`(사업) · `members`(사람-사업 N:M 연결) ·
`meetings`(주간회의 + 재정 + 회원변동) · `entries`(개인 주간입력) ·
`updates`(사업별 업데이트) · `schedule`(일정).

**3개 화면**
- **개인 입력** — 주차·이름을 고르면 담당 사업이 자동 표시. 지난주/다음주 동향,
  사업별 진행상황, 주간 일정을 선택형 위주로 입력.
- **주간회의** — 회원변동·재정 요약, 사람별 동향, 사업유형별 진행상황을 자동
  집계해 회의용 대시보드로 표시.
- **사람·사업 관리** — 사람/사업 등록과 사람–사업 연결을 관리.

**데이터 공유/백업** — 상단의 *내보내기/가져오기*로 JSON 파일을 주고받아 백업하거나
데이터를 공유합니다. localStorage는 브라우저별 저장이므로, 팀 전체 실시간 공유가
필요하면 아래의 cafe24 PHP+MySQL 백엔드로 확장하세요.

### cafe24 팀 공유 백엔드 (선택)

기본 상태(파일 업로드만)에서는 각자 브라우저에 저장됩니다. 아래 두 파일을 쓰면
모든 구성원이 한 DB를 공유합니다.

- `config.php` — cafe24 MySQL 접속정보. cafe24 매니저 > 나의서비스관리 > MySQL 에서
  DB를 신청(무료)하고 비밀번호를 설정한 뒤, 호스트(`localhost`)·아이디·비밀번호·DB명을 채웁니다.
- `api.php` — JSON 저장 API. 표(`kv`)는 첫 호출 때 자동 생성되므로 별도 설치가 없습니다.

설정 절차:
1. 전체 파일을 cafe24 웹폴더(`/www`)에 FTP 업로드.
2. `config.php` 에 MySQL 접속정보 입력.
3. **`사이트주소/check.php` 에 접속해 PHP/MySQL 지원과 접속정보를 진단** (지원 여부가
   불확실할 때 가장 빠른 확인 방법, 확인 후 삭제 권장).
4. 진단이 "성공"이면 `meeting.js` 상단 `CONFIG.api` 를 `'api.php'` 로 변경(같은 폴더 기준).
5. 외부 공개 서버라면 `config.php` 의 `API_TOKEN` 과 `meeting.js` 의 `CONFIG.token` 을
   동일한 값으로 설정해 간단히 보호.

> cafe24 웹호스팅은 PHP와 MySQL을 기본 제공합니다(phpMyAdmin 포함). MySQL 지원 여부가
> 불확실하면 cafe24 매니저의 MySQL 메뉴에서 DB 신청 가능 여부로 확인할 수 있습니다.

### index.html

메인 페이지는 `Nanum Gothic` 폰트를 불러오고, 헤더에 기념일과 D‑데이 카운트다운을 표시합니다. 본문에는 **오늘의 카드뉴스** 영역이 있으며, `script.js`가 `posts.json`을 읽어 해당 날짜의 카드뉴스를 자동으로 채워 넣습니다.

### style.css

간단한 레이아웃과 색상 테마를 정의합니다. 반응형 디자인을 적용하여 모바일 화면에서도 1–2개 카드가 한 줄에 표시되도록 구성했습니다. 필요에 따라 색상 값을 수정하여 브랜드 톤에 맞출 수 있습니다.

### script.js

* **D‑데이 타이머** – `targetDate` 변수를 수정하여 목표 날짜를 변경할 수 있습니다. 현재는 `2026-04-23T00:00:00+09:00`로 설정되어 있습니다. 자바스크립트가 현재 날짜와 목표 날짜의 차이를 계산하여 헤더에 `D-30`, `D-29` … 등으로 표시합니다. 당일에는 “오늘은 기념일입니다!”를 표시하고, 날짜가 지나면 “기념일이 지났습니다.”로 변경됩니다.
* **카드뉴스 로딩** – 페이지 로드 시 `posts.json`을 불러와 오늘 날짜와 일치하는 게시물만 필터링합니다. 해당 날짜의 카드뉴스가 없으면 안내 문구를 출력합니다. 새 게시물을 추가하거나 수정할 때는 `posts.json`을 편집하세요.

### posts.json 편집 방법

`posts.json` 파일은 카드뉴스를 날짜별로 저장하는 간단한 JSON 구조입니다. 예시는 아래와 같습니다.

```json
{
  "posts": [
    {
      "date": "2026-03-11",
      "title": "40주년 준비: 연구소 역사 소개",
      "content": "한국노동사회연구소는 지난 40년 동안 노동정책과 노사관계 연구의 중심이었습니다...",
      "image": "assets/card1.png"
    }
    // ... 추가 게시물 ...
  ]
}
```

새로운 카드뉴스를 추가하려면:

1. `assets/` 폴더에 이미지 파일을 추가합니다. 파일 이름은 공백 없이 영문/숫자를 사용합니다.
2. `posts.json`의 `posts` 배열에 아래와 같은 객체를 추가합니다.
   ```json
   {
     "date": "2026-03-12",        // 게시할 날짜를 YYYY-MM-DD 형식으로 입력
     "title": "카드뉴스 제목",
     "content": "카드뉴스 내용 요약...",
     "image": "assets/새이미지.png" // 1번에서 추가한 파일 경로
   }
   ```
3. 날짜가 동일한 게시물을 여러 개 추가하면 페이지에서 2–3개 카드가 한꺼번에 표시됩니다.

### 사이트 호스팅 방법

1. 이 `anniversary_website` 폴더 전체를 [GitHub Pages](https://pages.github.com/), [Netlify](https://www.netlify.com/) 등의 정적 호스팅 서비스 저장소에 업로드합니다.
2. 루트 경로(`index.html`)가 웹사이트의 첫 페이지가 되도록 설정하면 자동으로 카운트다운과 카드뉴스가 표시됩니다.
3. 매일 카드뉴스를 업데이트하려면 새로운 이미지와 게시물을 `assets/` 및 `posts.json`에 추가하고 변경사항을 서버에 반영하세요.
